<task type="auto" id="02-01-T4">
  <name>Implement REST Endpoints for Problems and Contests</name>
  <description>
    Build and mount FastAPI routers:
    - `backend/app/api/v1/problems.py`:
      - `POST /api/v1/problems`: Create problem (Organizer/Admin).
      - `GET /api/v1/problems`: List problems.
      - `GET /api/v1/problems/{id}`: Get problem details and current version.
      - `POST /api/v1/problems/{id}/versions`: Create version.
      - `POST /api/v1/problems/{id}/versions/{version_id}/testcases`: Add testcase.
      - `GET /api/v1/problems/{id}/versions/{version_id}/testcases`: Get testcases (filtered by caller role).
    - `backend/app/api/v1/contests.py`:
      - `POST /api/v1/contests`: Create contest (Organizer/Admin).
      - `GET /api/v1/contests`: List public/user contests.
      - `GET /api/v1/contests/time`: Authoritative server time endpoint.
      - `GET /api/v1/contests/{id_or_slug}`: Get contest details and dynamic status.
      - `POST /api/v1/contests/{id}/register`: Register for contest.
      - `POST /api/v1/contests/{id}/problems`: Add problem to contest (Organizer/Admin).
      - `GET /api/v1/contests/{id}/problems`: Get contest problems (gated by contest ACTIVE state or Organizer role).
    - Mount in `backend/app/api/v1/router.py`.
  </description>
  <verify>
    `python -c "from app.main import app; openapi = app.openapi(); assert '/api/v1/contests' in openapi['paths']; assert '/api/v1/problems' in openapi['paths']; print('Contest and Problem endpoints registered')"`
  </verify>
  <done>All REST endpoints exposed and verified in OpenAPI schema.</done>
</task>
